# 🎯 Number Guessing Game

A fun Number Guessing Game made in Python!

## How to Play
1. Run the game
2. I will choose a secret number between 1 to 100
3. You have to guess it
4. I will tell you if your guess is Too Low or Too High
5. Keep guessing until you Win!
